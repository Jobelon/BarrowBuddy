# Contributing to Borrow Buddy

Thanks for helping improve Borrow Buddy.

## Before You Start

- Search existing issues before opening a new one.
- For larger changes, open an issue first so the approach can be discussed.
- Keep changes focused and avoid mixing unrelated cleanup into a pull request.

## Issues

Use the issue templates to report reproducible problems or suggest product improvements. Include enough context for someone else to understand the problem without needing to guess at the expected behavior.

## Pull Requests

1. Create a branch for the change.
2. Make focused commits with clear messages.
3. Update relevant documentation when behavior or project direction changes.
4. Check the change locally before opening the pull request.
5. Complete the pull-request checklist and respond to review feedback.

Pull requests should explain what changed, why it changed, and how it was verified.
