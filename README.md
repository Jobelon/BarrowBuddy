# Borrow Buddy

Borrow Buddy is an app concept for making it easier to borrow, lend, and keep track of shared items.

This repository currently contains the project presentation and supporting project notes. Product and implementation details will be added as the app develops.

- [`Names/Conde.txt`](Names/Conde.txt): contributor information
